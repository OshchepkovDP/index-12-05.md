### Задание 2

Выполните объяснение и анализ следующего запроса:

```select distinct concat(c.last_name, ' ', c.first_name), sum(p.amount) over (partition by c.customer_id, f.title)
from payment p, rental r, customer c, inventory i, film f
where date(p.payment_date) = '2005-07-30' and p.payment_date = r.rental_date and r.customer_id = c.customer_id and i.inventory_id = r.inventory_id```

перечислите узкие места;
Оптимизируйте запрос: внесите корректировки по использованию операторов при необходимости добавления индексов.

Запрос собирает информацию о клиентах и их платежах за 30.07.2005, использует функцию SUM OVER для подсчёт общей суммы платежей,
объединяет данные из таблиц 1) платежи, 2) аренда, 3)клиенты, 4) инвентарь, 5) фильмы

Узкие места: 1) использование функции SUM OVER, что может быть ресурсоёмким при большом объёме данных, 3) отсутствие явных индексов

Оптимизированный запрос
SELECT DISTINCT 
    CONCAT(c.last_name, ' ', c.first_name),
    SUM(p.amount) OVER (PARTITION BY c.customer_id, f.title)
FROM payment p
JOIN rental r ON p.rental_id = r.rental_id
JOIN customer c ON r.customer_id = c.customer_id
JOIN inventory i ON r.inventory_id = i.inventory_id
JOIN film f ON i.film_id = f.film_id
WHERE p.payment_date >= '2005-07-30 00:00:00'
  AND p.payment_date < '2005-07-31 00:00:00'
